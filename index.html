共同骨架

  • 三条接缝：控制面（stdio JSON-RPC）、模型面（本地网关 + activation token）、工具面（自挂 MCP server）
  • 五阶段连续长大：L0 跑通 → L1 看见事件流 → L2 长出 SSE 页面 → L3 换自己的工具 → L4 摘掉真 key
  • 终态：一个本地页面 + 真实流式输出 + 一个只读 MCP 工具 + 真 key 不进引擎进程
  • 只借 StaffDeck 的三个接口分界线，不借它 12 万行的体量
