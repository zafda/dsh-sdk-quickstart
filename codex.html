DeepSeek Harness（dsh）SDK 快速入门：大纲计划

状态：待审核；本文件只规划教学内容、实验与验收，不含教材正文、示例代码或安装命令。

建议路线：60 分钟建立可复述的模型，再用同一个「投放日报小助手」完成 L0–L4。动手预算 3 小时 50 分钟，合计 4 小时 50 分钟。 保留你建议的五阶段顺序；L3 的运行时兼容问题由作者在写作前解决。

1. 教学范围与成品画面

最终小应用拟只有一个本地页面：输入一个投放活动的问题，回答逐段出现，旁边显示工具调用及结束状态；工具从虚构的本地投放日报读取数据。模型请求经过本地网关，真 key 只由网关持有。

只借 StaffDeck 的三个接口分界线：宿主如何指挥引擎、引擎如何请求模型、引擎如何调用业务工具。产品功能控制在单用户、单次在途任务、一个只读工具、一种上游模型协议；不引入员工管理、SOP、多租户、数据库、进程池或桌面打包。

教学默认条件：macOS 14+ arm64；Linux x64/arm64 给出对应说明；Python ≥3.10。Windows 不进入本路线。默认读者能读改基本 Python，但没接触过 dsh SDK；这项假设列入末尾待拍板项。

每章采用同一讲解顺序：先预告要看到的画面 → 解释参与者各管什么 → 挂上本章需要的真实名称 → 用一句话复述。 动手章再补完整运行步骤、预期现象、失败时的处理和一个小改动练习。上述内容均留待审核通过后撰写。

3.2 L0：跑通 hello，留下第一份会话记录

  • 目标： 在独立实验目录安装 SDK，使用官方最小组合跑通一句 hello；建立后续复用的调用入口，并备好小份虚构投放日报。
  • 屏幕现象： 终端出现模型回复和会话标识；指定的会话目录下出现 JSONL 记录；程序正常退出后，引擎子进程被关闭。回复与记录都能定位到本次任务。
  • 代码预算： 应用源码新增 25–35 行，累计 25–35 行；另有约 80–110 行官方最小组合配置，后续逐步删减。
  • 概念位置： 宿主通过 Python SDK 走控制面驱动引擎；模型面暂用直接连接，工具面暂保留官方最小组合。
  • 实操 25 分钟： 环境与安装 10 分钟，调用与运行 10 分钟，查看记录与复述 5 分钟。
  • 验收与小改动： 能把输入换成自己的问候再跑一次；能说明工作目录和会话目录为什么不同。复用和更换会话标识各做一次对照。
  • 开跑前必须说清： minimal.cordis.yml 使用 danger-full-access；Bash 和编辑器能改运行进程有权限访问的任何路径。所有阶段均在专门的 work/ 实验目录运行，只放虚构资料；独立目录方便控制实验内容，本身不是沙箱。不能把配置中的 cwd 讲成访问范围限制。

3.3 L1：看见真实事件流

  • 目标： 在 L0 的调用入口增加通知观察，不等最终结果才展示过程；让模型查看实验目录内的样例文件，制造一次可观察的工具调用。
  • 屏幕现象： 终端按实际到达顺序显示回合、步骤、增量回复、工具调用与结果；任务进入空闲后，再显示最终回复和结束原因。无工具的 hello 与有工具的任务能看出差别。
  • 代码预算： 新增 25–35 行，累计 50–70 行；沿用 L0 配置。
  • 概念位置： 控制面上的实时通知承载引擎事件，会话日志保存可回看的事实；它们将成为 L2 界面的数据源。
  • 实操 25 分钟： 观察入口 10 分钟，两类任务对照 10 分钟，复述与小改动 5 分钟。
  • 验收与小改动： 只展示文字增量，再切回完整事件视图；指出工具发生在哪两个模型步骤之间。不会把「每个任务必有工具调用」写成保证。

写作时会解释通知范围与根会话事件集合的区别；主线不增加子代理实验，也不为展示复杂性额外加载子代理工具。

3.4 L2：同一份调用入口长出 SSE 界面

  • 目标： 给已有调用入口增加轻量 Python HTTP 后端和原生 HTML/JavaScript 页面，将回调中的通知经队列转成浏览器 SSE 流。
  • 屏幕现象： 点击发送后，完整任务结束前就能看到真实增量文本；工具执行状态独立显示；结束后页面恢复可发送状态。故意造成一次请求失败时，页面能显示错误并结束等待。
  • 代码预算： 新增 110–150 行，累计 160–220 行，含约 50–70 行页面代码；不引入前端构建链。
  • 概念位置： 浏览器—宿主新增一条界面传输线；宿主—引擎仍走 stdio JSON-RPC。SSE 不是给引擎换协议，也不是把模型网关直接暴露给浏览器。
  • 实操 45 分钟： 后端与队列 15 分钟，页面 15 分钟，流式及异常验收 10 分钟，复述 5 分钟。
  • 验收与小改动： 改变提问使回答变长，确认输出发生在任务结束之前；切换事件区的显示。最终消息不能再次追加一遍，造成文字重复。

实施约束：同步 SDK 调用放在后台执行，不能阻塞 HTTP 服务；页面只接收需要展示的内容，不把全部原始通知、请求头和模型请求正文转发到前端。每次只允许一个任务在途。浏览器断开后要结束相关工作并清理引擎，不能把连接关闭写成官方支持的逐会话取消接口。

3.5 L3：只挂自己的 MCP 投放工具

  • 目标： 保留 L2 页面、事件展示与 SDK 调用入口；移除最小组合中暴露给模型的 Bash 和编辑器，挂入自己的本地 MCP server，提供一个只读投放日报查询工具。
  • 屏幕现象： 同一页面出现带服务器命名空间的 MCP 工具调用及结果；回答引用虚构日报中的数据。检查实际发往模型的工具清单，确认只剩自定义工具，原先的 Bash 和编辑器已不再暴露。
  • 代码预算： 新增 70–100 行，累计 230–320 行；配置删掉不再需要的工具行，补入 MCP 连接配置。配置的行数变化另列，不算应用源码。
  • 概念位置： 工具面换了提供方，控制面和界面传输线保持原有职责；模型仍由 dsh 负责选择工具并继续后续步骤。工具只读固定实验资料，不接受任意文件路径或命令。
  • 实操 45 分钟： 运行时及连接检查 10 分钟，工具和组合调整 15 分钟，工具清单与执行验收 15 分钟，复述 5 分钟。
  • 验收与小改动： 修改一份虚构日报中的数据，再提问观察结果变化；关闭 MCP 服务做一次失败对照。不能只凭模型说「没有 Bash」来验收工具已移除。

连接方式拟采用与 StaffDeck 一致的 Streamable HTTP；MCP 服务由本地后端承载，避免多部署一个业务服务。SDK 的阻塞调用继续在后台执行，以保证工具请求能被宿主正常处理。

已发现的运行时卡点： 官方源码的 SDK runtime 依赖清单没有直接列出 @deepseek-ai/dsh-mcp-client；对应单文件入口把包名解析到自身封闭的运行时树。不能据此承诺「给 wheel 加一行配置就能加载 MCP」。

拟定处理顺序：作者先核验目标发行版的实际插件可用性；若捆绑运行时不可加载，则优先验证官方通用 dsh-jsonrpc-agent 入口和项目内插件依赖，通过当前 SDK 的 launch_args_override 选择运行时。保持原有应用调用入口，只更换运行载体和配置；不沿用 StaffDeck 的旧版启动参数。

上述备用路线已有官方文件依据，但本轮未安装或运行验证。正式教材必须只留下作者实跑通过的一条路线，并把新增安装成本计入本阶段；如果完整路线不能落入本预算，先修订计划供审核，不把编译整个仓库留作读者隐含作业。

3.6 L4：真 key 只留在独立模型网关

  • 目标： 保留页面和自定义工具，将模型请求改经本机 OpenAI 兼容网关；网关持有真 key，引擎只拿到一次任务的 activation token。
  • 屏幕现象： 页面仍可流式回答并调用工具；网关只显示脱敏请求记录；引擎启动环境与组合配置的检查结果显示没有真 key；任务结束后，旧 token 再发请求会被拒绝。
  • 代码预算： 新增 140–190 行，累计 370–510 行；最终组合配置预计另有 35–60 行，虚构数据另计。
  • 概念位置： 模型面被换成本地受控出口，控制面和工具面继续保留。这里先做同协议流式转发，不编写新的 dsh 模型适配器，不实现 StaffDeck 的多协议转换。
  • 实操 55 分钟： 网关及转发 20 分钟，凭据生命周期与干净启动 15 分钟，端到端及失效验收 15 分钟，复述 5 分钟。
  • 验收与小改动： 完成一次至少调用一个工具的任务，确认同一任务内多次模型请求都能成功；任务结束后旧 token 失效。修改虚构日报后重跑，确认 L2 的流式和 L3 的工具仍然工作。

本阶段拟用最小生命周期：一次用户任务创建一个新引擎和一个新 token，任务结束撤销 token 并关闭引擎。这里的「一次性」指一次任务的授权生命周期，不能解释成只允许一次 HTTP 请求；一个工具回合通常需要继续请求模型。StaffDeck 源码还有进程池复用和阶段重绑定，作为边注说明，不要求复刻。

真 key 拟由独立网关进程通过隐藏输入读取并仅保存在内存中；应用后端与引擎从不含真 key 的环境重新启动。L0–L3 已经继承过凭据的旧进程必须退出。不会声称仅改变模型地址就自动完成凭据隔离。

写作时还会覆盖两个实际来源：Python SDK 的 env 是合并父环境，并非替换；运行入口还会读取工作目录中的 .env。因此运行目录不放含真 key 的配置文件，也不能只覆盖一个变量后就宣称检查通过。凭据检查只输出是否存在，不打印真值；本实验验证凭据不被传入引擎，不扩张成操作系统级的恶意进程隔离承诺。
